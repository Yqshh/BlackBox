# Участие в разработке

Спасибо за интерес к BlackBox.

## Локальный запуск

```bash
npm install
npm run dev
```

Требуется Node.js 20+.

## Перед PR

```bash
npm run typecheck
npm test
npm run build
npm run build:single
```

## Правила

- Не коммитьте реальные пароли, заметки, бэкапы и скриншоты личных данных.
- Секреты и криптография — только через `src/core`; не дублируйте Web Crypto в компонентах.
- Новые данные должны проходить через `normalizeVault` и иметь разумные значения по умолчанию.
- Пользовательские строки рендерятся как текст React; HTML — только через `MarkdownPreview` с DOMPurify.
- Для новых функций добавляйте тесты, если логика не сводится к вёрстке.
- Соблюдайте стиль существующих файлов: функциональные компоненты, явные типы, небольшие модули.

## Коммиты

Желателен Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`, `chore:`.
