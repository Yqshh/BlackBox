# Changelog

Все заметные изменения проекта. Формат вдохновлён Keep a Changelog, версии — SemVer.

## [Unreleased]

### Исправлено

- Чек-лист в редакторе заметок: текст пункта снова стоит в одну строку с чекбоксом, а не уезжает под него. ## [2.0.0] — 2026-10-27

Полное переписывание одиночного `passwords.html` в модульный проект.

### Добавлено

- Главный экран с обзором, статистикой, аудитом безопасности и быстрыми действиями.
- Раздел заметок: блокноты, теги, Markdown-редактор, просмотр, разделённый режим, автосохранение, закрепление.
- Глобальный поиск по всему хранилищу и командная палитра `Ctrl + K`.
- Светлая/тёмная/системная темы и адаптивная мобильная вёрстка.
- Импорт резервных копий: новый и старый шифрованный формат, открытый JSON.
- Прямой перенос старой IndexedDB `vaultaccess_db`.
- Импорт старых JSON-бэкапов `passwords.html`.
- Смена мастер-пароля с перешифрованием данных.
- Автобэкап в файл через File System Access API.
- Экспорт: шифрованный JSON, открытый JSON, CSV, заметки в Markdown.
- Аудит слабых, старых и повторяющихся паролей.
- Тесты Vitest (крипто, TOTP RFC 6238, поиск, миграция, нормализация, Markdown/XSS).
- GitHub Actions CI, Dependabot, README, SECURITY, MIT-лицензия.

### Изменено

- PBKDF2: 310 000 → 600 000 итераций для новых хранилищ.
- Пароли больше не попадают в поисковый индекс.
- Главный экран и модальные окна переработаны; добавлены клавиатурная навигация и focus trap.
- Новые заметки создаются с пустым заголовком и плейсхолдером, а не с текстом «Без названия».
- Дублирование ресурсов, перемещение разделов/ресурсов/учёток, история паролей до 25 записей.
- Копирование секретов очищает буфер обмена по таймеру.

### Исправлено

- Фокус в модальных окнах больше не сбрасывается на каждом введённом символе.
- Устранены лишние мобильные кнопки на десктопе.
- Палитра команд получила полноценную вёрстку.
- Исправлены склонения числительных и отображение пустых заголовков заметок.

### Удалено

- CDN-зависимости Tailwind CSS и Font Awesome: приложение полностью офлайн, стили и иконки встроены.

## [1.0.0] — 2026

Первая версия: одиночный `passwords.html` с паролями, TOTP, генератором, историей и бэкапами.
